# TikTok India Unlock

Hands a TikTok link to a working mirror when tiktok.com is blocked or region-gated, with an editable mirror list.

## Install

Follow the [install guide](https://github.com/chirag127/userscript-install-guide), then install:

```
https://github.com/chirag127/tiktok-india-unlock-userscript/raw/main/tiktok-india-unlock-userscript.user.js
```

## Usage

Press the 🌍 chip (Alt+U) or paste a link. Mirrors are templates with `{id}`/`{user}` and are editable.

## Limits

- A userscript cannot run on a domain that never loads, so this is a handoff, not a tunnel
- Mirrors die often, edit the list
- No login on mirrors
